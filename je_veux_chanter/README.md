# je veux chanter

Operacao de conteudo premium com IA para a marca Defesa Auto.

## Objetivo

Construir e operar uma fabrica de conteudo com:
- embaixador fixo (imagem + voz)
- roteiro orientado para conversao
- curadoria musical via interface Artlist Pro
- publicacao diaria em Instagram, TikTok e YouTube Shorts

## Estrutura

- `docs/`: guias da marca e plano de MVP
- `prompts/`: prompts oficiais dos agents
- `content/`: calendario e roteiros
- `ops/`: checklist operacional e template de publicacao

## Regra de marca

- Azul: `#0D1C3B`
- Verde: `#18914F`
- Branco: `#F8F8F8`

Tom de comunicacao: juridico-tech, direto, confiavel.

## Inicio rapido

1. Ler `docs/DEFESA_AUTO_BRAND.md`.
2. Rodar o prompt de `prompts/orquestrador.md`.
3. Produzir os videos do dia em `content/calendario_14_dias.md`.
4. Validar no `prompts/qa.md`.
5. Publicar e registrar no `ops/publish_sheet_template.csv`.
